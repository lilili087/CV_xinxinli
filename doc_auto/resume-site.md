# 个人简历网站说明

- 产出文件：`index.html`
- 开发方式：原生 `HTML + CSS + JavaScript` 单文件实现
- 页面结构：首页、实习经历、项目经历、校园经历、生活与爱好
- 视觉风格：继续参考 `UI参考图1 / UI参考图2`，整站保持 `浅米白 + 鼠尾草灰 + 深墨绿` 的清新高级配色；标题采用更有杂志感的 serif 字体，正文保持清晰克制的 sans 字体，整体方向偏简约、大气、清新
- 面板约定：首页与内页统一使用轻透的浅米白面板与卡片体系，减少高饱和玻璃感和重阴影；模块标题、轮播大标题采用更有编辑感的层级区分，强化可读性
- 内容展示调整：整站保持纵向滚动结构，同时恢复 `实习经历 / 项目经历 / 生活与爱好` 的模块内横向滑动展示；`校园经历` 在桌面端恢复更舒展的双栏正文结构，项目卡片也恢复为更有横向展示感的多列布局
- 交互说明：整站外层保持标准纵向滚动页面；导航固定在右上角并平滑跳转到对应 section；外层不再接管滚轮做横向位移，仅保留 `实习经历 / 项目经历 / 生活与爱好 / 我的溜达日记` 等内部轮播或横向结构的滚轮增强
- 布局重点：首页首屏左侧继续展示头像、基础信息与 Skills，右侧展示 `理性产品人 / 有温度的推动者 / 核心优势` 三张内容卡；首页左侧头像、姓名、基础信息与 Skills 保持左对齐；其余页面按 `实习经历 / 项目经历 / 校园经历 / 生活与爱好` 四个模块自上而下纵向排列，并统一继承首页背景氛围。当前已补充统一 spacing 体系：桌面端内容宽度控制在 `1280px`，页面横向 gutter 控制在 `24px - 40px`，section 垂直节奏进一步压缩到约 `48px - 60px`，并统一 panel/card padding 与内容块 gap，使各模块更像同一页中的连续上下排布
- 项目模块：`项目经历` 保留模块内左右滑动的 showcase，分为 `Vibe Coding / Coze 多模态 Agent搭建 / 竞赛经历：校园商业选址智能体` 三个 slide；底部指示器与左右切换按钮水平对齐在同一行，`Vibe Coding` 恢复三列展示，整体更偏清爽的横向作品集浏览感
- 链接样式：`项目经历` 轮播卡片中的 `项目链接 / PRD` 使用更轻量的蓝色文字型链接，并去掉尾部箭头图标
- 首页微调：桌面端左侧姓名前图标仅保留 `👩`，并保持与姓名水平排列；首页左侧个人信息外层玻璃框已去除，改为透明容器；桌面端头像在不超过右侧文本框高度的前提下进一步放大，且头像与其余文字信息统一左对齐；`Skills` 上移到邮箱信息下方。首页与其余内容模块均不再强制等高撑满浏览器，改为根据内容自然决定文本框高度
- 响应式补充：导航在窄窗口下支持横向滚动以防止换行遮挡；首页在平板和窄浏览器窗口下切换为单列；各模块卡片宽高与边距改为基于视口的自适应取值，兼顾桌面端与手机端。平板端横向 gutter 收敛到约 `20px - 28px`，移动端左右留白统一为 `16px`
- 头像逻辑：在 JavaScript 中按 `avatar.png -> avatar.jpg -> avatar.jpeg` 顺序探测本地头像；未命中时使用占位样式保持布局稳定
- 背景逻辑：所有模块统一使用 `background.jpg` 作为共享背景图；若资源缺失，则回退到内置 SVG 占位插画
- 内容来源：以 `个人网站.md` 为主，补充 `简历.md` 中的时间线、岗位名称与量化成果
- 备份机制：新增 `scripts/create-project-backup.mjs`，执行 `node scripts/create-project-backup.mjs` 后会把当前项目完整快照到 `backups/时间戳/`；脚本会自动排除 `.git`、`backups`、`node_modules`，并在生成新快照后仅保留最近 `5` 份备份，每份快照都会附带 `backup-metadata.json` 记录文件清单与创建时间
- 验证方式：新增 `test_backup_rotation.mjs` 用于校验“只保留最近 5 份备份”的轮转逻辑；原有 `verify_resume_site.mjs` 继续用于验证站点页面内容
- 内容扩充：
  - `实习经历`：保留高德、百度、小冰、南湖研究院四段完整经历；当前继续采用模块内横向轮播浏览方式，并补齐指示器、左右按钮与滚轮横向浏览能力。四张实习卡已根据最新文案改为“摘要 + 重点模块卡片”的融合展示结构，不再单独展示上方成果指标卡；高德与百度的摘要已按新表述同步，小冰与南湖的关键结果则合并进下方重点模块中呈现，横向阅读更紧凑
  - `项目经历`：拆分为 `Vibe Coding`（面试大王、特价机票发现平台、个人网站）、`Coze 多模态 Agent搭建`、`竞赛经历`（校园商业选址智能体）三组内容；其中 `个人网站｜自我介绍网站` 项目已加入 `Vibe Coding`，标注 `Cursor 编程`、补充 PRD 链接并预留项目链接位置；`Coze 多模态 Agent搭建` 两个项目分别接入 `coze图片生成.png` 与重新刷新的 `coze视频生成.png` 作为项目示意图；整体恢复为更强的横向展示感和多列作品集式排版
