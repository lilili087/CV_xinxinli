# 个人简历网站说明

- 产出文件：`index.html`
- 开发方式：原生 `HTML + CSS + JavaScript` 单文件实现
- 页面结构：首页、实习经历、项目经历、校园经历、生活与爱好
- 视觉风格：首页改为参考示意图的全屏双栏首屏布局，左侧 `4`、右侧 `6` 的比例展示个人信息卡与内容卡片；所有横向模块统一使用 `background.jpg` 作为底图，整体配色调整为冷白、雾蓝、石墨灰体系，参考 Apple 官网的克制高级感；当前已继续提高首页与其余模块的背景遮罩层，并同步提升内容卡片底色透明白强度，进一步压低底图存在感
- 面板约定：首页继续保留轻玻璃卡片氛围；非首页模块则统一转为更偏“正文阅读”的浅色面板与内容卡，弱化强装饰感，增强文字可读性
- 内容展示调整：放大整站内容区最大宽度，提升模块卡片可用高度，并收紧标题区、卡片内边距与模块间距，让一屏内可见的具体内容更多；同时取消“文本框强制撑满浏览器”的策略，改为按具体内容自适应高度，仅在超出可视区时再启用内部滚动，避免卡片内部留白过多；本轮继续将 `实习经历 / 项目经历 / 校园经历` 的主要内容排版收敛为更易读的单列文字结构
- 交互说明：整站外层现已从横向滑屏切换为标准纵向滚动页面；导航仍固定在右上角并平滑跳转到对应 section；外层不再接管滚轮做横向位移，仅保留 `项目经历 / 生活与爱好 / 我的溜达日记` 等模块内部的横向滚动增强
- 布局重点：首页首屏左侧展示头像、基础信息与 Skills，右侧展示 `理性产品人 / 有温度的推动者 / 核心优势` 三张内容卡；首页左侧头像、姓名、基础信息与 Skills 现统一改为左对齐；其余页面按 `实习经历 / 项目经历 / 校园经历 / 生活与爱好` 四个模块自上而下纵向排列
- 项目模块：`项目经历` 现改为模块内左右滑动的 showcase，分为 `Vibe Coding / Coze 多模态 Agent搭建 / 竞赛经历：校园商业选址智能体` 三个 slide；支持底部指示器、左右切换按钮与横向吸附滚动；项目与生活模块的左右切换按钮现统一下移到指示器两侧并水平对齐
- 链接样式：`项目经历` 轮播卡片中的 `项目链接 / PRD` 现改为蓝色文字型链接，并去掉尾部箭头图标，减弱按钮感
- 首页微调：桌面端左侧姓名前图标现仅保留 `👩`，并保持与姓名水平排列；首页左侧个人信息外层玻璃框现已去除，改为透明容器；桌面端头像在不超过右侧文本框高度的前提下进一步放大，且头像与其余文字信息统一改为左对齐。`Skills` 上移到邮箱信息下方。首页右侧三张卡片文案现同步到 `个人网站.md` 第 `21-60` 行，其中 `理性产品人` 按原文断句展示，`有温度的推动者` 的第二段合并为单句展示，`核心优势` 去除 `1/2/3` 编号，仅保留标题与两条要点。当前首页与其余内容模块均不再强制等高撑满浏览器，改为根据内容自然决定文本框高度
- 响应式补充：导航在窄窗口下支持横向滚动防止换行遮挡；首页在平板和窄浏览器窗口下切换为单列；各模块卡片宽高与边距改为基于视口的自适应取值，兼顾桌面端与手机端
- 头像逻辑：在 JavaScript 中按 `avatar.png -> avatar.jpg -> avatar.jpeg` 顺序探测本地头像；未命中时使用占位样式保持布局稳定
- 背景逻辑：所有模块统一使用 `background.jpg` 作为共享背景图；若资源缺失，则回退到内置 SVG 占位插画
- 内容来源：以 `个人网站.md` 为主，补充 `简历.md` 中的时间线、岗位名称与量化成果
- 内容扩充：
  - `实习经历`：保留高德、百度、小冰、南湖研究院四段完整经历
  - `项目经历`：拆分为 `Vibe Coding`（面试大王、特价机票发现平台、个人网站）、`Coze 多模态 Agent搭建`、`竞赛经历`（校园商业选址智能体）三组内容；其中 `个人网站｜自我介绍网站` 项目已加入 `Vibe Coding`，标注 `Cursor 编程`、补充 PRD 链接并预留项目链接位置，当前进展文案更新为“已基于 Cursor 完成多轮页面搭建与交互迭代，后续需持续补充作品集/经历等内容，同时优化各部分美观度”；`Coze 多模态 Agent搭建` 两个项目现已分别接入 `coze图片生成.png` 与重新刷新的 `coze视频生成.png` 作为项目示意图；当前项目模块在保留轮播结构的同时，单个 slide 内项目内容已调整为更偏正文阅读的单列排版，链接样式改为蓝色文字链接
  - `校园经历`：仅保留学生工作与提炼后的成长收获；学生工作现收敛为 `北京邮电大学学生记者团｜总负责人` 与 `团委新媒体中心｜副主任` 两段经历，并按 `个人网站.md` 第 `325-349` 行优化文案；`我学到的事` 内容现与 `校园经历` 标题下的总述融合展示，不再以单独区块出现；`初雪推送`、`一周CP` 的图片占位现已移除，改为在两段学生工作经历内部各自补充一段 `What I Learned` 收尾总结；模块标题右上角辅助标签已移除，标题下导语改为整行铺满文本框；当前正文卡片已统一弱化标签装饰，强调段落与列表阅读体验
  - `生活与爱好`：改为与 `项目经历` 同款的模块内横向轮播，拆分为 `我的支教生活 / 摄影日常 / 我的溜达日记` 三屏内容；三张生活卡片头部右侧的时间 / 摘要信息现已移除，让说明文字可横向铺满；`我的溜达日记` 当前仍保留原有城市卡片样式与横向时间轴类型，但已将 10 个城市位置调整为“上方 5 个、下方 5 个”的两排排布，并用一套新的转折连接线串联上下两排；当前生活模块整体也已同步弱化卡片装饰感，让文字说明更容易阅读，其余图片与文字内容保持不变
