# 个人简历网站说明

- 产出文件：`index.html`
- 开发方式：原生 `HTML + CSS + JavaScript` 单文件实现
- 页面结构：首页、实习经历、项目经历、校园经历、生活与爱好
- 视觉风格：本轮参考 `UI参考图1 / UI参考图2`，将整站从偏冷白玻璃态进一步收敛到 `浅米白 + 鼠尾草灰 + 深墨绿` 的清新高级配色；首页与其余页面统一改为同源背景图层，均使用 `background.jpg` + 浅米白遮罩 + 柔和鼠尾草色叠层，弱化底图存在感，同时引入更具编辑感的 `Libre Bodoni + Public Sans` 字体组合
- 面板约定：首页与内页统一使用轻透的浅米白面板与卡片体系，继续保留通透感，但减少高饱和玻璃感和重阴影；模块标题、轮播大标题采用更有杂志感的 serif 标题，正文保持清晰克制的 sans 字体，整体更简约、大气、清新
- 内容展示调整：整站继续保持纵向滚动结构，但重新恢复 `实习经历 / 项目经历 / 生活与爱好` 的模块内横向滑动展示；`校园经历` 在桌面端恢复更舒展的双栏正文结构，项目卡片也从先前的单列阅读态恢复为更有横向展示感的多列布局
- 交互说明：整站外层保持标准纵向滚动页面；导航固定在右上角并平滑跳转到对应 section；外层不再接管滚轮做横向位移，仅保留 `实习经历 / 项目经历 / 生活与爱好 / 我的溜达日记` 等内部轮播或横向结构的滚轮增强，同时补充 `prefers-reduced-motion` 降低动画策略
- 布局重点：首页首屏左侧继续展示头像、基础信息与 Skills，右侧展示 `理性产品人 / 有温度的推动者 / 核心优势` 三张内容卡；首页左侧头像、姓名、基础信息与 Skills 继续保持左对齐；其余页面按 `实习经历 / 项目经历 / 校园经历 / 生活与爱好` 四个模块自上而下纵向排列，但各 section 现统一继承首页同款背景氛围
- 项目模块：`项目经历` 继续保留模块内左右滑动的 showcase，分为 `Vibe Coding / Coze 多模态 Agent搭建 / 竞赛经历：校园商业选址智能体` 三个 slide；底部指示器与左右切换按钮继续水平对齐在同一行，`Vibe Coding` 恢复三列展示，整体更偏清爽的横向作品集浏览感
- 链接样式：`项目经历` 轮播卡片中的 `项目链接 / PRD` 现改为蓝色文字型链接，并去掉尾部箭头图标，减弱按钮感
- 首页微调：桌面端左侧姓名前图标现仅保留 `👩`，并保持与姓名水平排列；首页左侧个人信息外层玻璃框现已去除，改为透明容器；桌面端头像在不超过右侧文本框高度的前提下进一步放大，且头像与其余文字信息统一改为左对齐。`Skills` 上移到邮箱信息下方。首页右侧三张卡片文案现同步到 `个人网站.md` 第 `21-60` 行，其中 `理性产品人` 按原文断句展示，`有温度的推动者` 的第二段合并为单句展示，`核心优势` 去除 `1/2/3` 编号，仅保留标题与两条要点。当前首页与其余内容模块均不再强制等高撑满浏览器，改为根据内容自然决定文本框高度
- 响应式补充：导航在窄窗口下支持横向滚动防止换行遮挡；首页在平板和窄浏览器窗口下切换为单列；各模块卡片宽高与边距改为基于视口的自适应取值，兼顾桌面端与手机端
- 头像逻辑：在 JavaScript 中按 `avatar.png -> avatar.jpg -> avatar.jpeg` 顺序探测本地头像；未命中时使用占位样式保持布局稳定
- 背景逻辑：所有模块统一使用 `background.jpg` 作为共享背景图；若资源缺失，则回退到内置 SVG 占位插画
- 内容来源：以 `个人网站.md` 为主，补充 `简历.md` 中的时间线、岗位名称与量化成果
- 备份机制：新增 `scripts/create-project-backup.mjs`，执行 `node scripts/create-project-backup.mjs` 后会把当前项目完整快照到 `backups/时间戳/`；脚本会自动排除 `.git`、`backups`、`node_modules`，并在生成新快照后仅保留最近 `5` 份备份，每份快照都会附带 `backup-metadata.json` 记录文件清单与创建时间
- 验证方式：新增 `test_backup_rotation.mjs` 用于校验“只保留最近 5 份备份”的轮转逻辑；原有 `verify_resume_site.mjs` 继续用于验证站点页面内容
- 内容扩充：
  - `实习经历`：保留高德、百度、小冰、南湖研究院四段完整经历；本轮已恢复为模块内横向轮播浏览方式，并补齐指示器、左右按钮与滚轮横向浏览能力
  - `项目经历`：拆分为 `Vibe Coding`（面试大王、特价机票发现平台、个人网站）、`Coze 多模态 Agent搭建`、`竞赛经历`（校园商业选址智能体）三组内容；其中 `个人网站｜自我介绍网站` 项目已加入 `Vibe Coding`，标注 `Cursor 编程`、补充 PRD 链接并预留项目链接位置，当前进展文案更新为“已基于 Cursor 完成多轮页面搭建与交互迭代，后续需持续补充作品集/经历等内容，同时优化各部分美观度”；`Coze 多模态 Agent搭建` 两个项目现已分别接入 `coze图片生成.png` 与重新刷新的 `coze视频生成.png` 作为项目示意图；本轮已恢复更强的横向展示感，多列项目卡片与整体作品集式排版同步回归
  - `校园经历`：仅保留学生工作与提炼后的成长收获；学生工作现收敛为 `北京邮电大学学生记者团｜总负责人` 与 `团委新媒体中心｜副主任` 两段经历，并按 `个人网站.md` 第 `325-349` 行优化文案；`我学到的事` 内容现与 `校园经历` 标题下的总述融合展示，不再以单独区块出现；`初雪推送`、`一周CP` 的图片占位现已移除，改为在两段学生工作经历内部各自补充一段 `What I Learned` 收尾总结；模块标题右上角辅助标签已移除，标题下导语改为整行铺满文本框；当前桌面端恢复更舒展的双栏正文阅读结构
  - `生活与爱好`：改为与 `项目经历` 同款的模块内横向轮播，拆分为 `我的支教生活 / 摄影日常 / 我的溜达日记` 三屏内容；三张生活卡片头部右侧的时间 / 摘要信息现已移除，让说明文字可横向铺满；`我的溜达日记` 当前仍保留原有城市卡片样式与横向时间轴类型，但已将 10 个城市位置调整为“上方 5 个、下方 5 个”的两排排布，并用一套新的转折连接线串联上下两排；本轮继续统一到新的浅米白面板与同源背景体系中
